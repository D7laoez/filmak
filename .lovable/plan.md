# خارطة طريق تطوير فيلمك

الاقتراحات كثيرة وكل بند يحتاج تصميم مستقل. رتّبتها بترتيب أولوية عملي: القيمة العالية والاعتماد الأقل أولاً. ننفّذها على مراحل — كل مرحلة قابلة للشحن لوحدها.

## المرحلة 1 — الأساسيات (تنفيذ فوري)

- **قسم مسلسلات مستقل**: تبويب Movies / Series في الرئيسية، صفوف مماثلة (trending, top rated, popular, on air, airing today) + بحث + تصنيفات المسلسلات + صفحة `/tv/$id`.
- **صفحة تصنيف مستقلة**: `/genre/$id` مع pagination (زر "المزيد") وترتيب (شعبية / تقييم / حداثة). الشيبس في الرئيسية تصير روابط للصفحة.
- **الفلاتر المتقدمة** داخل صفحة التصنيف: سنة، بلد إنتاج، لغة، مدة، تقييم أدنى، عدد مصوّتين.

## المرحلة 2 — مزامنة الحالة والمشاركة

- **مزامنة URL كاملة**: اللغة، البحث، التصنيف، الترتيب، الفلاتر — كلها في `search params` عبر `validateSearch` (روابط قابلة للمشاركة والحفظ).
- **og:image ديناميكي لكل فلم/مسلسل**: تعديل `head()` في `/movie/$id` و`/tv/$id` ليستخدم صورة الملصق بحجم `w1280` كصورة معاينة عند المشاركة.
- **مشاركة الفلم بزر Copy Link + Web Share API**.

## المرحلة 3 — قوائم المستخدم الموسّعة

قاعدة بيانات جديدة تستبدل جدول `favorites` الحالي بجدول موحّد:

```text
user_lists(user_id, media_type, media_id, status, rating, note, created_at)
status: 'favorite' | 'watchlist' | 'watched'
rating: 1..10 nullable
```

- ثلاث قوائم مرئية: **مفضلة، شاهدته، شاهد لاحقاً**.
- **تقييم شخصي بالنجوم** لكل عنصر.
- **مشاركة قائمة عامة** برابط `/u/$userId/list/$status` (RLS يسمح بقراءة عامة للعناصر المُعلَّمة كـshared).
- **إحصائيات شخصية**: أكثر تصنيف تشاهده، متوسط تقييماتك، عدد الساعات، أفضل سنة، top 5.

## المرحلة 4 — الذكاء والبحث

- **توصيات شخصية**: يستخدم Lovable AI (`google/gemini-3-flash-preview`) ويتغذّى من مفضلاتك + شاهدته + تقييماتك، يرجع أفلام/مسلسلات جديدة مع سبب.
- **بحث ذكي متسامح**: تصحيح إملائي عبر TMDB search + fallback على AI. بحث بالممثل/المخرج (`/search/person` ثم `/person/$id/movie_credits`).
- **اقتراحات مباشرة أثناء الكتابة** (debounced dropdown).

## المرحلة 5 — تجربة التطبيق

- **الوضع الفاتح/الداكن**: تبديل يدوي + احترام `prefers-color-scheme`، حفظ بالـlocalStorage، بدون وميض عبر `ScriptOnce`.
- **PWA offline**: `vite-plugin-pwa` مع `generateSW`، NetworkFirst للصفحات، CacheFirst للأصول، مع الحماية من التسجيل في preview (حسب skill الرسمي).
- **إشعارات ويب** (اختياري): اشتراك على "قريباً" — تنبيه عند صدور الفلم. يحتاج service worker منفصل + Web Push + جدول اشتراكات.

## تفاصيل تقنية

- كل استدعاءات TMDB في `createServerFn` تحت `src/lib/*.functions.ts` (سيرفر فقط، مفتاح TMDB في `process.env.TMDB_API_KEY`).
- كل صفحة جديدة تحصل على `head()` مستقل مع title/description/og مترجَمة.
- تحديث `favorites.functions.ts` والـUI ليستهلك جدول `user_lists` مع migration ينقل البيانات الحالية.
- استخدام TanStack Query + `ensureQueryData` + `useSuspenseQuery` لكل قراءة.
- كل جدول جديد يشمل GRANTs + RLS + policies scoped بـ`auth.uid()`.
